Thunderbird 115+ 用アドオン。メール閲覧画面のツールバーに「日本語に翻訳」ボタンを追加し、表示中メールの件名と本文を英語→日本語に翻訳します。

## インストール
1. 下の `translate-en-ja.xpi` をダウンロード
2. Thunderbird → アドオンとテーマ → 歯車アイコン → 「ファイルからアドオンをインストール…」→ `.xpi` を選択
3. 未署名のため警告が出ます。詳細は README を参照してください。

## プライバシー
翻訳には Google 翻訳の非公式エンドポイントを使います。ポップアップの「翻訳する」ボタンを押した時だけ、件名と本文が送信されます。機密メールには使わないでください。非公式APIのため、予告なく使えなくなる可能性があります。

実機の Thunderbird での動作確認は未実施です（README のチェックリスト参照）。
