Thunderbird 115 以降用のアドオンです。

## v1.1.0 の新機能: AIで文章作成
メールの**作成ウィンドウ**に「AIで文章作成」ボタンが加わりました（Claude の API を使用）。
- **件名を考える**: 件名の候補を3つ作ります。
- **本文を考える**: 要点メモから本文案を作り、本文の先頭に挿入します（署名・引用は残ります）。
- **返信を考える**: 返信ウィンドウで、元メールを踏まえた返信案を作ります。
- **今の本文を整える**: 引用のない新規・下書きの本文を、確認のうえ整えて置き換えます。

AIの出力は、確認して「挿入」を押すまでメールには入りません。

## 初期設定（AI機能を使う場合）
1. https://console.anthropic.com で API キーを取得します（従量課金）。
2. アドオンの設定画面に API キーを貼り付けて「保存」します。

## これまでの機能
メール閲覧画面の「日本語に翻訳」ボタンで、件名と本文を英語から日本語に翻訳します（v1.0.0 から）。

## インストール
1. 下の `translate-en-ja-v1.1.0.xpi` をダウンロード
2. Thunderbird → アドオンとテーマ → 歯車アイコン → 「ファイルからアドオンをインストール…」→ `.xpi` を選択
3. 未署名のため警告が出ます。詳細は README を参照してください。

## プライバシー・注意
- 翻訳は Google 翻訳の非公式エンドポイントを使います。「翻訳する」ボタンを押した時だけ、件名と本文が送信されます。非公式APIのため、予告なく使えなくなる可能性があります。
- AI文章作成は、「作る」を押した時だけ、要点メモ・（モードにより）現在の件名/本文・返信元メール本文・設定の差出人メモが Anthropic（api.anthropic.com）に送信されます。送信内容は画面に一覧表示されます。添付は送信しません。
- API キーは Thunderbird のプロファイル内に**暗号化されずに**保存されます。設定画面の「キーを削除」で消せます。共有パソコンでは使わないでください。
- 機密性の高いメールには、翻訳・AIとも使わないでください。
