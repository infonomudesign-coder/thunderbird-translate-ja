# 英語→日本語 翻訳 + AI文章作成（Thunderbird アドオン）

メール閲覧画面のツールバーに「日本語に翻訳」ボタンを追加します。押すとポップアップが開き、
「翻訳する」を押すと、表示中メールの**件名と本文**を英語→日本語に翻訳します（原文/訳の切替・訳のコピー対応）。

## インストール
1. `bash build.sh` で `dist/translate-en-ja.xpi` を作成（作成済みならそのまま）。
2. Thunderbird → メニュー → アドオンとテーマ → 歯車アイコン → **ファイルからアドオンをインストール…** → `.xpi` を選択。
3. 未署名のため警告が出る場合は、`about:config` で `xpinstall.signatures.required` を `false` にするか、
   「アドオンをデバッグ」→「一時的なアドオンを読み込む」で `manifest.json` を指定（再起動で消えます）。
4. メールを開くと、メール表示ツールバーにボタンが出ます。出ない場合はツールバーを右クリック→「カスタマイズ」。

## AI文章作成（v1.1.0〜）
メール**作成ウィンドウ**のツールバーに「AIで文章作成」ボタンが追加されます（Claude の API を使用）。
- **件名を考える**: 要点メモと本文から、件名の候補を3つ出します。「この件名にする」で件名を置き換えます。
- **本文を考える**: 要点メモから本文案を作ります。「本文の先頭に挿入」で、既存の内容（署名・引用）を残したまま先頭に入ります。
- **返信を考える**: 返信の作成ウィンドウで、元メールを読んで返信案を作ります。
- **今の本文を整える**: 引用のない新規・下書きの本文だけが対象。確認のうえ、本文全体を置き換えます。

### 初期設定
1. https://console.anthropic.com で API キーを取得（従量課金）。
2. Thunderbird → アドオンとテーマ → このアドオンの「設定」→ API キーを貼り付けて「保存」。
3. モデルは既定 `claude-sonnet-5-5`。変更したい場合は設定のモデルIDを書き換えます（既定モデルの動作は実機未確認）。

### プライバシーと安全
- 「作る」を押した時だけ、要点メモ・トーン/言語・（モードにより）現在の件名/本文・返信元メール本文・設定の差出人メモが **Anthropic（api.anthropic.com）** に送信されます。送信内容は popup に一覧表示されます。添付は送信しません。
- 長い本文は上限（12000字）で切り詰め、その旨を表示します。
- API キーは Thunderbird のプロファイル内に**暗号化されずに**保存されます。設定画面の「キーを削除」で消せます。共有PCでは使わないでください。
- 元メールや下書きの文章は第三者のデータとして扱うよう AI に指示していますが、完全な防御ではありません。**AI の出力は、必ず内容を確認してから挿入してください**（自動では挿入されません）。

## 動作・仕様
- 対象: Thunderbird 115 以降。複数選択時は先頭のメールのみ。
- 本文: `text/plain` 優先、HTML のみのメールはテキスト化。添付ファイルや添付メールの内容は送信しません。
- 長文は約4000文字ごとに分割。総量は30000文字まで（超過分は翻訳されません）。途中で失敗した場合は翻訳済み部分を表示。
- ポップアップを閉じると翻訳は中断されます。

## プライバシー（重要）
翻訳には **Google 翻訳の非公式エンドポイント** (`translate.googleapis.com`) を使い、
「翻訳する」ボタンを押した時だけ件名・本文を送信します。ログ保存・永続化はしません。
機密メールや復号済みの暗号化メールでは使わないでください。非公式APIのため、仕様変更や制限で突然使えなくなる可能性があります。
差し替える場合は `lib/translate.js` の `translateChunk` を変更してください。
